The [MakeX official site](https://www.makex.cc/) is a starting point for locating authoritative material, not a claim that any specific 2026 document or page has been found or checked.

For each resource record source/publisher, document title, URL, revision/date, access date, applicability, reviewer/check status, and authorization to access, reproduce, or store material. All current document entries remain TBD.

Prefer links and original project notes with section references. Do not download, copy, or commit copyrighted material without appropriate authorization. Public availability alone does not establish redistribution permission. Resolve revision conflicts before deriving design requirements; this scaffold contains no downloaded source material.
