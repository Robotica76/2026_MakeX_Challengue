# Field resources

The field model used by the simulators is [`simulation/field2d/field_layout.py`](../../simulation/field2d/field_layout.py)
(2D) and [`simulation/field3d/field_model.py`](../../simulation/field3d/field_model.py) (3D details), built from the
rules guide V1.1 (section 4.2–4.3); dimensions not given in the guide are estimates noted in those
files. The Central Resource Area table used for the CAD fit checks: face at `y = 93` (robot frame),
posts `x ±276…320`, shelves `z 0…36` / `193…233`, roof `z 554…602`
([analysis](../../mechanical/assemblies/full_robot/v22/analysis/)).
