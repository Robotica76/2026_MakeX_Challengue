Course Introduction
	AI Camera 2.0 is a brand-new AI vision module specifically designed for K-12 artificial intelligence education, catering to a wide range of applications from basic programming instruction to advanced AI model training. This course seamlessly integrates the AI Camera with existing programming robots and platforms, such as mBot2 and CyberPi, providing a one-stop AI education solution. Students can directly control the module using either graphical programming or Python code, observe AI recognition results in real-time, and gain a deeper understanding of the principles behind artificial intelligence.
	The AI Camera course series comprises nine modules, covering face recognition, color recognition, gesture recognition, tag recognition, object recognition, speech recognition, text recognition, posture recognition, and path recognition.
	Comprehensive teaching resources are provided, including: PDF versions of lesson cases, editable Word versions of lesson cases, program source files for each course example, and corresponding demonstration videos.
