# xTool AI Camera 2.0 — Educational Projects

This directory contains the **9 Standard-aligned Projects** provided by xTool for the AI Camera 2.0.

The collection includes educational documentation, program source files, and references to video demonstrations.

## Project Organization

The original collection is stored in `AI Camera 2.0 Basic Projects/` and contains nine lessons, named `AI Camera 2.0_Lesson1` through `AI Camera 2.0_Lesson9`.

Each lesson follows the same directory structure:

| Directory | Description |
|---|---|
| `S01_PDF/` | PDF documentation and educational materials |
| `S02_Word/` | Editable Word documents |
| `S03_Program source files/` | Original program source files |
| `S04_Video display/` | Video demonstrations (hosted externally) |

The original directory organization and filenames have been preserved where applicable.

## Video Demonstrations

Each of the nine AI Camera 2.0 lessons includes video demonstrations originally provided by xTool.

Due to GitHub file size limitations, the video files are not included directly in this repository.

## Purpose

These projects provide supplementary educational resources for understanding and experimenting with the AI Camera 2.0.

They may be consulted during the development of computer vision functionality for the Storm Breaker robot.

## Integration Status

These projects are included as educational references only.

They are not part of the production competition software and have not been validated on the Storm Breaker robot.
