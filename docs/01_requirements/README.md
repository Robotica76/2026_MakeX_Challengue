`T02-R*` motors (#12), `T05-R*` chassis (#6), `T16-R*` modification stage, `T17-R*` battery and
power (#21). Design responses: [chassis design](../03_design/chassis/README.md), [v22 requirements check](../../mechanical/assemblies/full_robot/v22/README.md#requirements-check-cad).

## Review checklist

- Record edition, revision and page; do not paste rule text.
- Separate confirmed rule statements from assumptions and team goals.
- Resolve ambiguities with the competition authority and record the answer.
- Recheck architecture and tests when the rules guide changes.
