## Review checklist

- Record official edition, revision, section, and reference without reproducing protected documents.
- Separate confirmed source statements from assumptions and student design goals.
- Resolve ambiguous interpretations with the responsible competition authority; record the response reference.
- Recheck affected architecture and tests whenever a source revision changes.
- Record requirement changes and rationale in a [design log](../08_engineering_notebook/design_log/entry_template.md).
